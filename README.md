📌 Project Overview

DEVCONF 2026 is my Assignment 01 project, where I created a modern developer conference landing page using a clean and responsive design. The website presents important event information such as speakers, registration plans, FAQs, and navigation sections.

✨ Features
🎤 Speaker section
🎟️ Registration/pricing plans
❓ FAQ section
🧭 Navigation menu
📱 Responsive design
🎨 Clean and modern UI
🚀 Register Now call-to-action

Goal: The main goal of this assignment was to practice building a structured, visually appealing, and responsive web page based on a given design/reference.
